# Input tables

`shingetsu-ansi-colemak.tsv` and `shingetsu-ansi-qwerty.tsv` are the hazkey
romantables of the Shingetsu (新月) layout, copied unmodified from
[nagamine-git/shingetsu-layout](https://github.com/nagamine-git/shingetsu-layout)
commit `1bc5849` (MIT, see `LICENSE`). They are embedded into yaft at build
time and loaded by `apps/yaft/ime/Composer.cpp`.
